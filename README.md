# Projeto Integrador — Back-End  
## Buscador de Notícias da Paraíba (Softex / VBComunicacao)

Este repositório contém a parte **Back-End** do projeto integrador “Buscador de Notícias da Paraíba”.  

---

##  Sobre o Projeto
O Buscador de Notícias da Paraíba é um sistema desenvolvido para a empresa VBComunicacao, com o objetivo central de criar um buscador inteligente, capaz de:

- Coletar notícias automaticamente (via API autorizada)  
- classificação automatica por **pauta**, **município** e mais.
- Indexar notícias de fontes confiáveis da Paraíba.  
- Oferecer busca rápida, filtros (data, município, pauta, fonte) e alertas. 
- Exibir ranking das notícias mais acessadas.  
- Registrar log de acessos (para ranking e auditoria editorial).

Este repositório representa a parte Back-End responsável pela lógica do sistema, organização dos dados e regras de negócio.
